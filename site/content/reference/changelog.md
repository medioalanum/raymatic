## 0.2.0 — 2026-10-07

- Added explicit home, page, and article roles plus static alias redirects.
- Added bounded Pelican inspection and import for portable Markdown metadata, including YAML front matter, normalized source links, and opt-in generated image labels.
- Made migration reports and imported asset validation portable across Windows, macOS, and Linux path separators.


## 0.1.0 — 2026-09-28

First public release of Raymatic.

- Added the `new`, `dev`, `check`, and `build` workflow.
- Added deterministic Markdown-to-static-HTML publishing.
- Added structured diagnostics for invalid content, references, routes, and templates.
- Added safe staged output replacement and development recovery after invalid edits.

Known limitations and supported platform details are documented in the release notes.
